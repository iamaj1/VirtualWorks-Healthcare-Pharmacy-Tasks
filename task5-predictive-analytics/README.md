# Task 5 — Healthcare Predictive Analytics

## Objective
Demonstrate an educational logistic-regression classification workflow with a train/test split and common metrics.

## Run
```bash
python analysis.py
```

## Generated outputs
- `synthetic_readmission_data.csv`
- `synthetic_model_confusion_matrix.png`
- `model_evaluation.txt`

## Limitations
This model is trained entirely on fabricated data and is not clinically validated. Do not use it to estimate real readmission risk or guide care.
