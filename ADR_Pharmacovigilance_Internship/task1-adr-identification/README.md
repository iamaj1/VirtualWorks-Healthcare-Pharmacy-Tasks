# Task 1 — ADR Identification Basics

**Status note:** the dashboard screenshot showed this task as Approved, so this folder is for portfolio completeness; no resubmission is needed unless the portal later requests it.

## Objective
Practice recognizing a *suspected* adverse drug reaction (ADR) by documenting the event, suspect medicine, timing, relevant clinical context, and alternative explanations.

## Scenario
Fictional training case: an adult reports a new rash after starting Example Medicine A. The timing is recorded, but the relationship is not confirmed. The appropriate action is to document the event and route it for qualified review rather than declare causality.

## Principle
A suspected ADR is not proof that a medicine caused the event. Assess chronology, seriousness, competing causes, dechallenge/rechallenge where clinically available, and reporting requirements per the organization's SOP.
