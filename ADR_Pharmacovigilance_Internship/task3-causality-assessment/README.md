# Task 3 — Causality Assessment

## Objective
Document a structured, transparent causality assessment using WHO-UMC-style considerations: time relationship, alternative causes, dechallenge, rechallenge, and supportive evidence.

## Run
```bash
python causality_assessment.py
```

The script produces a case-by-case educational assessment table. The rule-based output is only a learning aid: it is not an official WHO assessment, Naranjo calculation, or final medical opinion. Always use the applicable SOP and qualified review. The result category can be Certain, Probable/Likely, Possible, or Unassessable based on the available scenario information.
