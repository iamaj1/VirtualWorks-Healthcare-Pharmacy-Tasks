# Healthcare & Pharmacy Data Analytics — Internship Project

This main project groups all five healthcare/pharmacy data analytics tasks into one portfolio project.

## Included tasks
1. [Task 1 — Healthcare Data Cleaning & Understanding](Task-1-Healthcare-Data-Cleaning/)
2. [Task 2 — Healthcare Data Visualization](Task-2-Healthcare-Data-Visualization/)
3. [Task 3 — Pharmacy Sales & Drug Analysis](Task-3-Pharmacy-Sales-and-Drug-Analysis/)
4. [Task 4 — Adverse Drug Reaction Data Analysis](Task-4-Adverse-Drug-Reaction-Analysis/)
5. [Task 5 — Healthcare Predictive Analytics](Task-5-Healthcare-Predictive-Analytics/)

## Tools
Python, pandas, NumPy, Matplotlib, scikit-learn.

## How to run
From this repository's root, install dependencies:
```bash
pip install -r requirements.txt
```
Each task contains an `analysis.py` script and a README with details. Run the script from its folder; generated CSVs, summaries, and charts are written to that same folder.

## Data transparency and limitations
All datasets are synthetic demonstrations. They are not real patient data, true sales data, or validated clinical/pharmacovigilance evidence. Any predictive model is educational and not for clinical decisions.
